# Agent 루프

Agent 루프는 LLM이 도구 호출을 멈출 때까지 다음을 반복한다.

1. 대화 기록(messages)과 도구 목록(tools)을 LLM에 보낸다.
2. LLM이 tool_calls를 돌려주면, 코드가 해당 도구를 실행한다.
3. 실행 결과를 role="tool" 메시지로 대화 기록에 추가하고 1로 돌아간다.
4. LLM이 텍스트로 답하면 루프를 끝낸다.

LLM은 도구를 직접 실행하지 않는다. 실행 여부와 권한 검사는 항상 애플리케이션 코드가 책임진다.
무한 반복을 막기 위해 최대 단계 수(MAX_STEPS)를 둔다.
